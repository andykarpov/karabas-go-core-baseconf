Main rules:

- temporary dir is ./tmp
- downloaded binaries are under ./bin
  place there any tools you need for work
- build dir is ./build
- prefer self-contained python scripts under ./tools
  each one should contain human-readable help and command parameters

Infosources:
- ./external/karabas-go
  karabas hardware main repository
- ./external/karabas-go-core-tsconf
  ZX Evolution TSConf core for Karabas GO
- ./external/zxevo.pentevo
  ZX Evolution BaseConf main repository
- internet searches are allowed also

Detailed goal:
Prepare Karabas-compatible core which will run ZX Evolution BaseConf.
- Real floppy support (based on Firefly FDC hdl sources)
- Real CF card support (Nemo IDE)
- BaseConf extended graphics
- USB Keyboard (with zx-evo ps/2 keybuffer emulation)
- USB mouse
- 2x Joysticks support (selectable via OSD)
- Turbosound + FM
- General Sound (2 MB)
- Provide OSD Menu by Win+ESC to change some settings

For the test - ./external/dune can be used - it is dune game port for BaseConf,
more details if needed is under ./external/retro-game-zxevo-dune
